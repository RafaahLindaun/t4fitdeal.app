# Imagens do Cardio

a partir de composições visuais geradas especificamente para o projeto.

- treadmill.png
- spinning.png
- elliptical.png
- stairs.png
- rowing.png
- walk.png
- swim.png

Todas seguem a mesma direção visual: fundo azul-marinho, pessoa/equipamento à
direita e área livre à esquerda para os textos da interface.
